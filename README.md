Solutions architect by day. Building with LLMs, agents and local models on the side.

I work in environments where the cost of getting it wrong is real — banking, fintech,
regulated systems. Lately that work increasingly involves figuring out where AI
actually belongs in the stack, and where it doesn't.

Particularly interested in local models: fine-tuning open-source LLMs, running
inference without sending data to the cloud, building agents that hold up in production.

**What I'm working on**

- Fine-tuning open-source models with LoRA/QLoRA on custom datasets
- Building multi-agent systems with LangChain and LangGraph
- Running local inference pipelines with Ollama — no API, no cloud, full control
- [`timectl`](https://github.com/CristianArielHz/timectl) — CLI tool for multi-project time tracking
- Writing about AI, agents and the practical side of building with LLMs
